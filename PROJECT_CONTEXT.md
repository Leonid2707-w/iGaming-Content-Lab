# iGaming Content Lab — контекст проекта

## Описание проекта

**iGaming Content Lab (iCL)** — профессиональное B2B-агентство по производству контента для вебмастеров, медиабаинговых команд и других участников iGaming-индустрии.

Главная задача iCL — снять с клиента рутинное производство контента и передать его профильной команде. Агентство создаёт материалы для социальных сетей, рекламные и AI-видеокреативы, YouTube-видео, SEO-контент и индивидуальные контентные решения.

iCL не занимается привлечением трафика и не является казино-сервисом. Публичный сайт позиционирует проект как технологичное контент-агентство и B2B-платформу.

Основная коммуникация с клиентами происходит через Telegram.

- Vite 6;
- React Router 7;
- Tailwind CSS 3.4;

- команды:

```bash

npm run build
npm run lint

```

Для остальных услуг стоимость указывается «по запросу», пока прайс не согласован.

## Принятые решения

### Позиционирование

- Сайт оформлен как профессиональное B2B-агентство.
- Из публичной части удалены внутренние цели, метрики и упоминания MVP.
- Удалены слот-машина, казино-элементы и кричащий неоновый стиль.
- Акцент сделан на технологии, AI-инструменты, GEO и контроль качества.

### Темы

- Поддерживаются полноценные светлая и тёмная темы.
- Переключатель находится в Header.
- Выбор сохраняется в `localStorage` под ключом `icl-theme`.
- До загрузки React тема применяется inline-скриптом в `index.html`, чтобы избежать вспышки неправильной темы.
- Цвета реализованы через семантические CSS variables.

### Оформление заказа

- Встроенная форма заменена глобальным модальным окном.
- Все кнопки «Заказать» используют `OrderModalContext`.
- Старые ссылки `/#order` автоматически открывают модальное окно.
- Первый шаг предлагает пять вариантов:
  - видео-креативы;
  - Telegram-посты;
  - YouTube;
  - ведение соцсетей;
  - другое.
- Для видео-креативов используется slider от 10 до 1000 с шагом 5 и расчётом стоимости.
- Для Telegram-постов применяется минимум 5 и цена $2 за пост.
- В форме остаются Telegram username, описание задачи и дополнительные комментарии.
- Email и загрузка файлов из формы заказа удалены.
- Модальное окно поддерживает Escape, закрытие по overlay, focus trap, scroll lock и полноэкранный мобильный режим.

### Анимации и доступность

- Motion используется для открытия/закрытия modal, переходов между шагами и карточек услуг.
- Сохранены мягкие scroll-reveal-анимации.
- Поддерживается `prefers-reduced-motion`.
- Контраст и компоненты адаптированы для обеих тем.

### Ограничения текущей версии

- Формы пока работают только на frontend: после отправки показывается success-состояние, но данные не передаются в API, Telegram-бота или CRM.
- Цены большинства услуг ещё не утверждены.
- Реальные клиентские кейсы, логотипы и отзывы пока отсутствуют.
